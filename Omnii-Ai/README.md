A sophisticated AI assistant with multi-provider support, advanced local intelligence, and a beautiful futuristic interface.

### **Market-Leading AI Capabilities**
- **Multi-Provider Integration**: Gemini 1.5 Pro/Flash, Llama 3.3 70B (Groq), DeepSeek-R1, Mistral Large, OpenAI, Grok

- **Advanced Local AI**: Comprehensive knowledge base without API requirements
- **Physics & Math**: Advanced calculations and explanations
- **Study & Office**: Productivity assistance and learning support
- **World Knowledge**: Extensive information across all domains

### **Beautiful Interface**

### **Productivity Features**

- **Image Generation**: High-quality images with professional prompts
- **Responsive Design**: Works perfectly on all devices
- **Performance Optimized**: GPU acceleration and smooth animations

## 🛠️ Getting Started

### **Option 1: Local Development**
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

### **Option 2: Online Deployment**
The app is already configured for Vercel deployment:

1. Go to [vercel.com](https://vercel.com)
2. Click "Add New Project"
3. Import from GitHub (select MrHacck/Omnii-Ai)
4. Click "Deploy"
5. Your app will be live in seconds!

## 🔑 Configuration

### **API Keys (Optional)**
Configure in Settings page or environment variables:
- `GEMINI_API_KEY`: Google Gemini API key
- `GROQ_API_KEY`: Groq API key (Llama 3.3 70B)
- `OPENROUTER_API_KEY`: OpenRouter API key (DeepSeek-R1)
- `MISTRAL_API_KEY`: Mistral API key
- `OPENAI_API_KEY`: OpenAI API key
- `XAI_API_KEY`: xAI Grok API key

### **Auto Mode**
Select "Auto Select" to let the AI automatically choose the best model:
- **Reasoning tasks** → DeepSeek-R1
- **Coding tasks** → Llama 3.3 70B
- **Creative tasks** → Gemini 1.5 Pro
- **General queries** → Optimized selection
